# 森灵消消乐

原创森林主题网页三消游戏。交换两个相邻精灵，连成 3 个或更多即可消除；4 连与 5 连会生成特殊萤光，连续掉落可触发连击加成。

## 本地运行

需要 Node.js 22.13+ 与 pnpm。

```bash
pnpm install
pnpm dev
```

浏览器访问终端显示的本地地址。

## 验证

```bash
pnpm test
```

该命令会执行正式构建，并验证服务端页面、三消逻辑入口、响应式样式与部署配置。

## 部署到 Render

仓库已包含 `render.yaml`。把代码推送到 GitHub 后，在 Render 中选择 **New > Blueprint** 并连接该仓库即可。免费计划、构建命令、启动命令与健康检查均已预设。
